# Чек-лист тестирования

Проверка по акту приёма-передачи (к ТЗ v1.2): блоки A — функциональность,
B — работоспособность, C — сквозные сценарии. 81 критерий.

Легенда статуса колонки «Автотест»: ✅ — покрыт автотестами (`python -m pytest`),
🔴 — проверяется только на живом окружении (Telegram + PaaS).

Подготовка: два аккаунта Telegram — **Админ** (ID из PRIMARY_ADMIN_ID) и
**Клиент**. У Админа открыто меню администратора.
