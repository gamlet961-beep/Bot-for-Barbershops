# Фаза 4 — Услуги и категории

> Отчёт по плану разработки (раздел 5.6). Статус: **завершена** 21.11.2026.

## Что сделано

- **`bot/db/repositories/services.py`**: список по категориям (активные /
  все), карточка услуги, создание, точечное обновление полей, скрытие
  (set_active) — soft delete без удаления строк.
- **`bot/handlers/admin/services.py`** — раздел «Услуги» (п. 4.3 ТЗ):
  - обзор: услуги по категориям с ценами, скрытые помечены, кнопки карточек;
  - добавление: название → цена (целое число рублей) → описание (можно
    «Пропустить») → категория (Стрижка / Борода и усы — фиксированный
    справочник, допущение № 2 плана);
  - карточка услуги с редактированием любого поля (название / цена /
    описание / категория) и переключателем «Скрыть из меню / Показать»;
  - при скрытии бот явно напоминает: существующие и будущие записи остаются
    активными и видимыми (A.3.5).
- Кнопка «Услуги» в меню админа открывает раздел (заглушка фазы 1 снята).

## Результат фазы

Полный CRUD услуг с категориями; скрытие услуги не затрагивает записи —
инвариант подтверждён тестом на реальном сценарии (запись → скрытие →
запись активна и видна админу).

## Зафиксированные решения

1. Категории — фиксированный справочник из двух позиций (ТЗ: «резерв —
   уточняется»); расширение выполняется миграцией, UI управления категориями
   не разрабатывается (out of scope).
2. Цена — целое число рублей; ввод с подсказкой и повтором при ошибке.
3. Скрытие обратимо (кнопка «Показать в меню» возвращается в карточке).
