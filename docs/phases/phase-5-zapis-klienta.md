# Фаза 5 — Сценарий записи клиента

> Отчёт по плану разработки (раздел 5.7). Статус: **завершена** 21.11.2026.

## Что сделано

Полный клиентский путь из раздела 5 ТЗ — три модуля обработчиков + FSM:

- **`bot/handlers/client/services.py`** — «Услуга» (п. 5.2):
  категории → услуги с названием, ценой и описанием; toggle-мультивыбор
  (✓ в тексте кнопки и списка); «Убрать последнюю»; счётчики выбранных по
  категориям; кнопка «Дата и время →».
- **`bot/handlers/client/datetime.py`** — «Дата и время» (п. 5.3):
  текущая неделя пн–вс — кнопки только у дней со свободными слотами (число
  слотов на кнопке); «Записаться на другую дату» — ввод ДД.ММ/ДД.ММ.ГГГГ с
  проверкой горизонта `BOOKING_HORIZON_DAYS`; свободные слоты дня; при
  отсутствии — «Нет доступных записей».
- **`bot/handlers/client/cart.py`** — «К записи» и оформление (п. 5.4–5.5):
  корзина (услуги, дата и день недели, время, итоговая сумма); «Оформить» →
  имя → телефон (валидация `+7…/8…/9…`, при ошибке — подсказка форматов) →
  экран согласия на обработку ПД с чекбоксом (кнопка «Записаться» появляется
  только после согласия — без него запись не создаётся) → транзакционная
  отправка. При занятом слоте — «Слот занят, выберите другое время» и
  возврат к слотам, корзина сохранена (UC-7). Ввод прерывается кнопками
  меню без «мусорных» данных.
- Экран согласия фиксирует `pd_consent_at`; связка `telegram_id + phone`
  записывается в users (A.1.5).
- Кнопки «Услуга», «Дата и время», «К записи» главного меню активны
  (заглушки фазы 1 сняты); «Мои записи» и «Связаться с барбером» — фаза 8.

Тексты сообщений — дословно из ТЗ: подтверждение (п. 5.6) отправляется
клиенту сервисом записи сразу после коммита, админам — уведомление со всеми
полями (п. 4.6).

## Результат фазы

Клиент проходит путь от выбора услуг до подтверждения записи; двойное
бронирование исключено на уровне транзакции (фаза 3) с корректным UX-возвратом.

## Зафиксированные решения

1. «Услуга» начинает выбор услуг заново; «Изменить услуги» из корзины —
   то же самое, но дата/слот сохраняются.
2. Услуга, скрытая после выбора, молча исключается из корзины; если не
   осталось ни одной — корзина признаётся устаревшей, оформление отклоняется.
3. Подтверждение и уведомление админам шлёт сервис записи (единая точка),
   обработчик не дублирует сообщения.
