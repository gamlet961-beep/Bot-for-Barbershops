# Инструкция администратора барбер-бота

Это руководство для владельца барбершопа. Прочитав его, вы сможете сами
настроить расписание, добавить услуги и начать принимать записи — без
участия разработчика.

## 1. Первый вход

- Бот узнаёт администратора по Telegram ID (список доступа задаётся при
  запуске). Ваш ID — это `PRIMARY_ADMIN_ID` из настроек.
- Узнать свой ID можно у бота @userinfobot.
- Откройте бота и нажмите **Start**. Если вы в списке доступа, бот покажет
  **меню администратора**:

  | Расписание | Услуги |
  |---|---|
  | **Записи** | **Управление админами** *(только основной админ)* |

- Клиенты (все остальные) видят своё меню: Услуга · Дата и время · К записи ·
  Мои записи · Связаться с барбером.

## 2. Расписание

Кнопка **«Расписание»** → четыре раздела.

### 2.1. Шаблон недели (обычные недели)

1. «Шаблон недели» → список всех 7 дней с текущим состоянием.
2. Выберите день (Пн…Вс).
3. «Рабочие часы» → введите интервал, например `10:00-20:00`
   — или «Выходной».

⚠️ **Интервал должен быть кратен 2 часам** (10:00–20:00 — можно,
10:00–19:00 — нельзя, бот попросит исправить). Бот сам нарежет день на
2-часовые слоты: 10:00–12:00, 12:00–14:00 и так далее. Один слот = один
клиент, независимо от числа услуг.

### 2.2. Исключения на дату (праздники, отпуска, переносы)

1. «Исключения на дату» → «Добавить исключение».
2. Введите дату (например `05.12` или `05.12.2026`).
3. Выберите: «Изменить часы» (введите интервал) или «Выходной / отпуск».

Исключение сильнее шаблона. «Удалить исключение» возвращает дату к
обычному недельному шаблону.

### 2.3. Блокировка слотов (занять время под себя)

1. «Блокировка слотов» → «Заблокировать слот» → дата.
2. Бот покажет сетку дня: ✖ занят записью, 🔒 заблокирован, ◻ свободен.
3. Нажмите 🔒 у свободного слота — он исчезнет из клиентской записи.

«Разблокировать» возвращает слот клиентам. Заблокировать можно только
существующие слоты дня.

### 2.4. Отменить рабочий день

1. «Отменить рабочий день» → дата.
2. Если на дату **есть активные записи**, бот предупредит и спросит
   «Да / Нет»:
   - **Да** — все записи на день автоматически отменятся, клиентам уйдут
     уведомления («рабочий день отменён»), слоты освободятся, а вам придёт
     отчёт по каждой отменённой записи;
   - **Нет** — ничего не изменится.
3. Если записей нет — день просто станет нерабочим.

## 3. Услуги

Кнопка **«Услуги»**: список по категориям («Стрижка», «Борода и усы»).

- **Добавить**: «➕ Добавить услугу» → название → цена (целое число рублей) →
  описание (или «Пропустить») → категория.
- **Редактировать**: нажмите на услугу → карточка → «Название» / «Цена» /
  «Описание» / «Категория».
- **Скрыть**: в карточке нажмите «🙈 Скрыть из меню». Услуга исчезнет из
  выбора клиентов, но **все существующие и будущие записи с ней останутся
  активными и видимыми** вам в разделе «Записи». «👁 Показать в меню»
  возвращает услугу.

## 4. Записи

Кнопка **«Записи»** сразу показывает записи на сегодня. Фильтры:

- **Сегодня / Завтра / Конкретная дата / Диапазон** — по датам;
- **Поиск по имени/телефону** — введите часть имени или номера;
- **Все предстоящие** — всё будущее в пределах горизонта записи (30 дней).

Нажмите на запись в списке → полная карточка (клиент, услуги, сумма, кто
создал, согласие на ПД).

- **Отменить запись**: в карточке → «🗑 Отменить запись» → подтвердите.
  Клиент получит уведомление, слот освободится.
- **Создать запись вручную** (например, человек позвонил по телефону):
  «➕ Создать запись вручную» → услуги → дата → свободный слот → имя →
  телефон → «Создать запись». Мгновенные уведомления никому не отправляются;
  вам придёт напоминание за 1 час до визита, как по всем записям.

## 5. Управление админами (только основной админ)

**«Управление админами»**: список администраторов и кнопки:

- «➕ Добавить админа» → пришлите Telegram ID (уточните у человека через
  @userinfobot);
- «➖ Удалить админа» → пришлите ID.

Второй админ видит расписание, услуги и записи наравне с вами, но не может
управлять админами. Себя (основного) удалить нельзя.

## 6. Что видит и получает клиент

- Выбор нескольких услуг сразу (сумма считается автоматически);
- календарь недели со свободными слотами + «Записаться на другую дату»
  (в пределах 30 дней);
- подтверждение записи сразу и напоминания **за 24 часа и за 2 часа**;
- «Мои записи» за последние 2 месяца с кнопкой «Отменить запись» — доступна,
  если до визита **больше 4 часов**; иначе бот предложит связаться с вами;
- «Связаться с барбером» — кнопка-ссылка на ваш личный чат
  (`BARBER_CONTACT_URL` в настройках бота).

## 7. Уведомления, которые приходят вам

| Событие | Когда |
|---|---|
| Новая запись клиента | сразу (имя, телефон, дата, время, услуги, сумма) |
| Напоминание о визите | за 1 час (по всем записям, включая ручные) |
| Клиент отменил запись | сразу |
| Клиент заблокировал бота | сразу (запись автоматически отменяется, слот освобождён) |
| Отчёт об отменённом дне | после удаления рабочего дня с записями |

## 8. Полезно знать

- Незавершённые диалоги (ввод даты, телефона и т.п.) прерываются командой
  `/start` или `/menu`.
- Отменённые записи не показываются ни клиенту, ни в списках раздела
  «Записи» — но остаются в базе для статистики.
- Через 2 месяца после визита имя и телефон клиента автоматически
  обезличиваются (152-ФЗ); дата, время, услуги и сумма сохраняются.
- Если бот «молчит» — проверьте пинг `https://<адрес-сервиса>/health`
  (должен отвечать `{"status": "ok"}`) и логи на хостинге.
